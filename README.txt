HYBRID Fitness

Host the contents of this folder on a static HTTPS host (for example GitHub Pages). Open the hosted URL in Safari on your iPhone, tap Share, then Add to Home Screen. Launch from the icon. Local storage is device/browser-specific; export JSON backups from Settings and restore them in the installed app. Offline access works after the first successful online load. Food search needs internet and uses Open Food Facts. Barcode digits can be typed; camera scanning is not implemented. No account or paid API is required. Hosting free-tier terms may vary.
